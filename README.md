> ### 💡 開発スタイルについて（AI活用の明記）

## 📂 収録プロジェクト一覧

### 1. [`資産管理/`](./資産管理) — 個人資産・支出統合管理システム ＆ モバイルWeb UI
複数の銀行・証券口座・暗号資産取引所（GMOコインAPI）の残高と、複数クレジットカード会社（JCB / セゾン / 三井住友）の明細CSVを一元管理し、純資産推移と支出カテゴリ内訳を可視化するシステムです。

- **主な設計・工夫点**:
  - **拡張性の高いCSVパーサー群 (`expenses/parsers/`)**: カード会社ごとに異なる文字コード（CP932/UTF-8）・ヘッダー位置・日付書式を共通インターフェースで吸収し、SHA-1ハッシュにより重複取込を防止
  - **NFKC正規化による自動仕分け (`expenses/category_rules.py`)**: 明細特有の全角英数字・カナ表記ゆれを正規化してキーワード分類
  - **マルチインターフェース**: Excelテンプレート入出力・HTMLダッシュボード自動生成・スマートフォン向けWebアプリUI（`app/`）に対応
- **テスト**: `pytest` による単体テスト **158件**（`資産管理/tests/`）

### 2. [`gmo_dca/`](./gmo_dca) — RSI連動スマートDCA（ドルコスト平均法）自動積立ボット
GMOコイン Private/Public API を利用し、BTC / ETH を毎月自動積立するボットです。単なる定額購入ではなく、日足RSI(14)に応じて購入額を動的に調整します。

- **主な設計・工夫点**:
  - **自作APIクライアント (`gmo_api.py`)**: HMAC-SHA256署名による認証、レート制限・エラーハンドリングを実装
  - **スマート積立ロジック**: RSI 70以上で買われすぎの局面では見送り、RSI 30未満の売られすぎ局面では購入予算を1.5倍にブースト
  - **二重発注防止ガード**: 約定履歴APIを照会し、当月すでに約定済みの場合は再発注を確実に防止
  - **CI/定期実行**: GitHub Actions (`.github/workflows/dca.yml`) によるスケジュール実行に対応
- **テスト**: `MagicMock` で外部通信・SMTPを完全分離した単体テスト **88件**（`gmo_dca/tests/`）

---

### 3. [`gmo_screener/`](./gmo_screener) — 暗号資産マルチ指標テクニカルスクリーナー
GMOコイン取扱いの全暗号資産銘柄を対象に、複数のテクニカル指標を計算して過熱感やトレンド転換シグナルを検知・通知するスクリーナーです。

- **主な設計・工夫点**:
  - **スクラッチ実装のテクニカル指標群 (`crypto_indicators.py`)**: Wilder方式RSI、MACD（EMA・シグナル・ヒストグラム）、ボリンジャーバンド（$\pm 2\sigma$・%B）、出来高急増倍率を外部TAライブラリに依存せず実装
  - **スコアリング＆HTML通知**: 複数指標の合致度に応じたアラート判定と視覚的なHTMLメール通知
- **テスト**: 境界値・ゼロ除算・トレンド転換を網羅した単体テスト **108件**（`gmo_screener/tests/`）

### 4. [`株/`](./株) — 日本株ファンダメンタルズ＆適時開示アナライザー

  - TDnet（適時開示情報閲覧サービス）から自社株買い等の資本政策開示を自動収集し、セクター分類・日次HTMLレポート生成・バックテスト検証を実行

### 5. [`訪問地マップ/`](./訪問地マップ) — 写真EXIF連動・訪問地記録マップWebアプリ

- **主な設計・工夫点**:

  - **地図テーマ着せ替え (`js/theme.js`)**: Leaflet.js 上で複数の地図タイルテーマをリアルタイム切り替え

```powershell

# Python リント＆フォーマットチェック
ruff check
ruff format --check

# JS / JSX / CSS リント＆フォーマットチェック
biome.cmd check
```
